An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: official names, descriptions and grades for every trophy, a guide in our own words with a cited source for each, a 3-stage roadmap to the platinum, the one potentially missable trophy flagged, and a checklist that saves in the browser with export/import, search, grade/kind/stage filters and a spoiler setting that hides story trophies until earned. Static files only — no build step, no network at run time.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or serve `app/` with any static file server.
